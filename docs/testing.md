### 1 GiB 本地端到端资源运行

独立预编译测试进程内同时运行协调服务、发布者和下载者。源文件为稀疏零数据，在各分片边界和末尾写入非零标记；**所有1GiB字节确实经过编码、UDP传输、恢复和独立SHA-256校验**。没有压缩。

```sh
go test -c -o /tmp/p2pfs-client.test ./internal/client
P2PFS_CLIENT_LARGE=1 /tmp/p2pfs-client.test -test.run '^TestGiBClientRoundTrip$' -test.v
```

2026-10-11 首次记录：编码8.115秒，总体31.481秒，下载载荷1,073,741,824字节，四次完整分片传输。Python resource.getrusage(RUSAGE_CHILDREN)记录该测试进程峰值 RSS **50,448KiB（约49.3MiB）**，退出码0。Go测试总时间31.66秒。

最终实现快照（本地 b9d604c，对应发布树的 GitHub提交5325391）再次运行：编码5.371秒，总体27.617秒，峰值RSS53,628KiB（约52.4MiB），四次完整分片、1,073,741,824字节实际载荷及最终SHA均通过。该次仍不含桌面WebView2。

此结果覆盖根模块后端并低于512MiB目标，但不含Wails/WebView2，也不是2核2GiB指定主机或公网性能证明。输入稀疏性影响存储设备表现；不得外推为一般磁盘吞吐。独立存储模块的两次实测见[存储记录](storage-test-results.md)。

100MiB真实UDP下载，固定与自适应各五轮，限速/均匀两个预设场景，共20/20成功。限速来源场景中位9.232秒→5.649秒（改善38.81%），均匀场景2.431秒→2.438秒（退化0.315%）。未更换场景、调算法或丢弃失败/慢样本；此场景刻意让固定策略偏好的来源限速，不是公网异构网络的代表性抽样。完整方案、逐轮时间及离散程度见[调度报告](scheduler-results.md)。
