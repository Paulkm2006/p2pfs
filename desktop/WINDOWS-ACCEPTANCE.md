# Windows GUI 人工验收清单

状态：待真实 Windows 环境执行。跨编译、mock bridge 的 DOM 测试不能代替以下验收。请记录操作系统版本、WebView2 版本、提交号、服务端版本与每项实际结果，不预填“通过”。

## 启动与显示

- [ ] Windows 10/11 x64 安装 WebView2 后运行 `bin/p2pfs.exe`，无空白页；中文显示正常。
- [ ] 900×650 最小窗口、1220×820 默认窗口及 125%/150% DPI 下，内容不重叠，按钮可见，列表能滚动。
- [ ] Tab 键能操作导航、输入框、按钮与弹出确认框；Esc 关闭确认框，焦点回到原操作。
- [ ] 未连接时发布/刷新不可用，首次启动打开连接设置，不显示虚构来源或进度。

## 会话、目录与文件选择

- [ ] 正确 HTTPS 配置可连接并显示服务端分配 UUID。错误证书/网络不可达显示实际错误，无绕过证书开关。
- [ ] HTTP 默认被拒绝；仅显式启用本机调试时允许回环 HTTP。
- [ ] 原生文件与目录选择正确显示；按取消不会发布文件、创建下载或改动目录。
- [ ] 原生保存对话框默认文件名被限制为单个合法 Windows 文件名；路径和保留设备名不被信任。
- [ ] 选择已存在的保存文件不会覆盖其内容；选择新文件名可创建任务。
- [ ] 同一个数据目录不能被切换到另一个协调服务；原配置重连可恢复 UUID/本机状态。
- [ ] 关闭窗口后传输/共享停止；再次启动不会留下两个仍在传输的实例。

## 发布、下载与共享

- [ ] 发布空文件、中文文件名、小文件、非整倍数长度文件，超过 1 GiB 显式拒绝。
- [ ] 两个同名不同内容版本在列表中分别显示；名称和版本筛选有效。
- [ ] 下载任务能显示真实的等待来源、下载、恢复/校验、完成与错误。
- [ ] 快速重复点击下载不会创建相同目标任务；暂停/继续/取消/重试重复操作状态一致。
- [ ] 弹出的取消确认使用 Esc 或“取消”退出时不停止传输；确认后才停止。
- [ ] 暂停后退出、重启并重连，可复用已校验完整分片，不把坏缓存计为进度。
- [ ] 至少三台来源保留互补索引，发布者离线后第四台设备可恢复文件，摘要一致。
- [ ] 直连/强制中转分别实际运行，界面结束的传输记录路径与日志一致。
- [ ] 停止某个来源后能换源；独立有效分片不足 4 个时等待，恢复来源后继续。
- [ ] 保留分片必须选择 0–5 中至少一个且没有重复；本机实际文件与持有声明一致。
- [ ] 停止共享默认保留缓存；显式清理只删除相应缓存，不删除原文件或下载结果，不破坏活动任务。
- [ ] 断开连接能停止正在进行的发布/保留操作，界面清除上次目录详情和可点击下载按钮。

## 统计与错误

- [ ] 上传速率上限和下载并发配置生效；配置为 0 上行限速表示无手动上限。
- [ ] 已校验分片数、已接收字节、实际来源/路径/每次平均速度符合实际传输记录。
- [ ] “重新统计”显示真实文件计数和占用；缓存详情标明检查时间语义。
- [ ] JSON 导出有效、可读、包含实际任务与传输记录，不含 DeviceSecret、Token 或 TURN 凭据。
- [ ] JSON 导出取消不写文件，既有文件不被覆盖。
- [ ] 服务端中断/断网时明确指出同步失败，仍保留上次结果的状态说明；恢复后可刷新。
- [ ] 无写权限、磁盘满、目标冲突、服务端认证错误显示可理解错误；不会显示“完成”。

## 证据

每项记录：结果、时间、版本、步骤、实际状态、日志/截图路径。凡未实际执行的项目保留未勾选，不从自动化测试推断人工验收完成。
