# p2pfs

软件工程实践小组项目：P2P 存储文件下载工具。

项目面向多设备文件共享场景，通过协调服务发现分片来源，由客户端从多个节点下载分片，并在部分节点不可用时利用 Reed–Solomon 纠删码恢复文件。

## 当前阶段

当前处于需求明确阶段。仓库中的需求文档为待小组评审的草案，尚未代表功能已经实现或测试已经通过。

## 已确定的技术约束

- 服务端：Go + Echo v5 + SQLite
- 客户端：Go + Wails 3
- 文件数据传输：UDP
- NAT 穿透：使用 STUN 辅助打洞
- 服务端职责：维护 P2P 设备在线状态和文件 chunk 分布

STUN 本身不保证任意网络之间都能建立直连。打洞失败的处理方式、首发操作系统和实验规模仍需在需求评审中确认。
